## FOV up/down correction

- Before W32 (`bugfix/fov-updown` 78bf427, not yet on develop) the client sent CompositorServices' bottom tangent as `Fov.up`: every stream so far was rendered 50 deg up / 45 deg down. With the fix it is 45 up / 50 down, the device's, and the eye axis sits 5.5 deg above the frame's centre.
- ALVR's convention: the 1:1 band spans eye UV [c0(1 + s), 1 - c0(1 - s)], c0 = (1 - c)/2, centre 0.5 + s c0 (`ALVRClient/Shaders.metal:152-157`; `FFR.swift:88-89` only rounds s to 2r px). Eye UV x runs from the temporal edge (R mirrored, `Shaders.metal:136-140`) and y from the top row, so a negative `center_shift_y` moves the band up. The axis-centred shift is (t_lo - t_hi)/(t_lo + t_hi)/(1 - c) with t_lo the temporal (x) or up (y) |tan| (`axis_shift` in the generator).
- `center_shift_y` for the axis variant (c 0.45): pre-W32 stream (up 1.1918, down 1) +0.159; corrected stream (up 1, down 1.1918) -0.159. This analysis has always used the device frustum, so its -0.159 is unchanged, but it suits only a client with the W32 fix; on a pre-W32 client (axis below the centre) it centres the band above the axis by twice the axis offset. `center_shift_x` is unaffected (+0.536).
- The simulator emulation assumes the W32 fix is on the client: `-ALVRDebugEyeTangents "L:<l>,<r>,<d>,<u>;R:..."` fills the gimmeTangents slots (left, right, bottom, top), which W32's `ViewLayout.fovAngles` packs as up = .w, down = .z. Without the fix the client sends d as up.

## Variants (derived from the visible field per fov scale)

- `asrun`: c 0.5/0.45, r 3/3, no shift. `off`: no foveation (coded = render).
- `axis`: c and r as `centred`, band centre on the eye axis (tan 0): shift 0.536/-0.159 at s = 1, from the tangents (see "FOV up/down correction").
- `centred`: c 0.5/0.45, r 3/3, band centre on the visible field's centre (midpoint of its edge tangents), shift = (fraction - 0.5)/((1 - c)/2), x from the temporal edge, y from the top.
- `wider`: r 2.5/2.5; c = the field's share of the frustum, widened in 0.001 steps until ALVR's rounded band holds the whole field; centred on it like `centred`.
- ALVR has one shift for both eyes (x mirrored for R); the shift is the mean of the per-eye values (equal for mirrored eyes).
- Coverage: only s = 1.0 covers the full frustum; every listed s still covers the visible field.
