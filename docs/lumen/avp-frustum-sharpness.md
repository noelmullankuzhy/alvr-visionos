# AVP frustum sharpness: fov scale x foveation x stream size

Predicted stream detail (px/deg) on the Vision Pro's recorded per-eye frustum, for choosing the server settings that the
`points-chart-avp.tsv` matrix then checks in the simulator (`-ALVRDebugEyeTangents`). Every figure comes from
`python3 tools/diag/avp-sharpness.py --full`, which uses `fov-overlay.py`'s ALVR foveation model (FFR.cpp, float32) and
its page prediction (render px/deg over the foveation squeeze). These are predictions, not measurements. The matrix run
(GM) checks the line positions; on-device sharpness is still unmeasured.

  AVP eye axis: shift = (near/(near+far) - 0.5)/((1-c)/2), using the temporal share for x and the up share for y,
  averaged over the eyes. ALVR has one shift for both eyes; x is mirrored for R.
- `off`: no foveation (coded = render).

**The sim shift is wrong-signed vertically for the AVP.** -0.159 comes from the old device model (up 1.0 < down 1.19).
The AVP's up tangent is larger than its down tangent (1.217 > 1.019), so its axis sits below the image centre and the
centring shift is +0.162. With -0.159 the band moves up, and detail 20 deg below the axis falls to 15 px/deg (below
the game's 19.5). The y sign convention comes from the model (W5a: see it on the chart before keeping it).

Coverage: only s = 1.0 covers the full AVP frustum. Below 1.0 the stream edge moves inside it (at 0.85 the L temporal
edge is at 56.5 deg instead of 60.7). The 66w convention, which insets the frustum by 15 deg, is covered from s ≥ 0.588.
